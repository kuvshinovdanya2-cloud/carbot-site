carbot

Automated content-posting tool for a car-related TikTok channel.

Terms of Service

This app is used to automate posting of vehicle listing content to the developer's own TikTok account. The account owner is responsible for all published content.

Privacy Policy

This app does not collect, store, or share personal data of TikTok users. It uses TikTok's Content Posting API only to publish content to the developer's own account, using access tokens obtained via standard OAuth authorization.
